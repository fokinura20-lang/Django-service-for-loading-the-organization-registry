# Django-сервис для загрузки реестра организаций

Проект для загрузки и хранения реестра организаций из CSV-файлов с валидацией данных, отслеживанием ошибок и истории загрузок.

## Требования

- Python 3.10+
- PostgreSQL 12+

## Правило обработки дубликатов
Повторный ИНН не создаёт новую организацию: запись игнорируется, счётчик duplicate_count увеличивается, а в LoadError сохраняется сообщение "Дубликат ИНН: <номер>". Уникальность обеспечена ограничением UNIQUE на уровне базы данных (unique=True в модели).

## Способ хранения ошибок
Каждая ошибочная строка сохраняется в LoadError: номер строки файла, исходные данные (raw_data) и текст ошибки. Если ошибок несколько, они объединяются в одну запись через "; ".

## Решение по транзакциям
Каждая организация сохраняется внутри transaction.atomic() (savepoint): при IntegrityError откатывается только эта строка, остальные обрабатываются дальше. Обновление итоговой статистики FileLoad выполняется после цикла. При критической ошибке (недоступность БД) загрузка остаётся в статусе PROCESSING/FAILED.

## Ограничения текущей реализации
- Контрольные цифры ИНН не проверяются, только формат (10 цифр).
- Загрузка построчная (без bulk_create), на очень больших файлах будет медленнее.
- Формат даты принимается строго YYYY-MM-DD.
